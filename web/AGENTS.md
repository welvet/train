# Next.js project guidance

This project uses a current Next.js version whose APIs and conventions may
differ from older examples. Read the relevant guide in
`node_modules/next/dist/docs/` before changing framework-specific code.

The production build must remain a static export. Do not add server-only
features, API routes, or backend connections without an explicit product
decision to change that contract.
